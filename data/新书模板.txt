================================================================
新书模板 —— 复制、改字、粘贴
================================================================

【粘贴位置】

打开 data/books.js，翻到最底下，长这样：

      "status": "wish",
      "summary": "配合《四书章句集注》一起读。"
    }              ← 给这个右花括号后面加一个英文逗号 ,
  ];               ← 把模板粘在这一行的上面

改完应该像这样：

    },             ← 逗号
    {              ← 从这里开始是粘贴进来的新书
      "title": "新书名字",
      "author": "作者"
    }              ← 注意：最后这一条后面不要加逗号
  ];

----------------------------------------------------------------

【模板 1 · 想读】（还没开始看，只记个名字）

  {
    "title": "书名",
    "author": "作者",
    "category": "历史",
    "tags": ["标签一", "标签二"],
    "status": "wish"
  }

----------------------------------------------------------------

【模板 2 · 在读】（正在看，会显示进度条）

  {
    "title": "书名",
    "author": "作者",
    "category": "历史",
    "tags": ["标签一", "标签二"],
    "status": "reading",
    "progress": 35,
    "startedAt": "2026-09-01"
  }

----------------------------------------------------------------

【模板 3 · 已读】（看完了，带评分、笔记、摘句）

  {
    "title": "书名",
    "author": "作者",
    "publisher": "出版社",
    "year": 2020,
    "category": "历史",
    "tags": ["标签一", "标签二"],
    "status": "done",
    "rating": 5,
    "startedAt": "2026-07-01",
    "finishedAt": "2026-08-20",
    "summary": "一句话简介",
    "notes": "读书笔记，支持换行",
    "quotes": ["摘句一", "摘句二"],
    "link": "https://book.douban.com/..."
  }

----------------------------------------------------------------

【字段说明】

  必填的只有 title（书名）和 status（状态），
  其余字段不想要就直接删掉那一行，不影响显示。

  status      只能是这三个：wish 想读 / reading 在读 / done 已读
  progress    0 到 100 的数字，只有"在读"才显示进度条
  rating      0 到 5 的数字，0 就是未评分
  日期        必须写成 2026-08-20 这种格式，前后带英文双引号
  tags        标签，用英文双引号包起来，中间英文逗号隔开
  notes       笔记，想换行就写 \n（反斜杠加字母 n）
  quotes      摘句，一条一个，用英文逗号隔开
  cover       封面图片。留着不写，页面会自动配一张彩色书封

【最容易写错的三个地方】

  1. 逗号用了中文逗号，—— 必须是英文 ,
  2. 最后一条后面多了一个逗号 —— 最后一条的 } 后面不要加
  3. 引号用了中文引号 “ ” —— 必须是英文 " "

  拿不准的时候，照着上面模板原样复制再改里面的字，最保险。
